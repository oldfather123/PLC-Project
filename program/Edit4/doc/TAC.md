# 三地址码原理与作用

## 1. 什么是三地址码

三地址码（Three-Address Code，TAC）是一种中间代码表示形式，每条指令最多包含三个地址（操作数）：
- **两个源操作数**
- **一个目标操作数**

### 基本形式
```
result = operand1 operator operand2
```

例如：
```
t1 = a + b    // t1是结果，a和b是操作数
t2 = -x       // t2是结果，x是操作数
goto L1       // 无条件跳转
if x goto L2  // 条件跳转
```

## 2. 三地址码的特点

### 2.1 线性化表示
将复杂的嵌套表达式分解为简单的线性指令序列。

**原始代码：**
```c
int result = (a + b) * (c - d);
```

**三地址码：**
```
t1 = a + b
t2 = c - d
t3 = t1 * t2
result = t3
```

### 2.2 显式临时变量
引入临时变量来存储中间计算结果，使计算过程可见。

### 2.3 控制流显式化
用跳转指令明确表示程序的控制流。

**原始代码：**
```c
if (x > 0) {
    y = x + 1;
} else {
    y = x - 1;
}
```

**三地址码：**
```
t1 = x > 0
if !t1 goto else_label
y = x + 1
goto end_label
else_label:
y = x - 1
end_label:
```

## 3. 三地址码的核心组成

### 3.1 指令类型

#### 算术运算指令
```
t1 = a + b    // 加法
t2 = a - b    // 减法
t3 = a * b    // 乘法
t4 = a / b    // 除法
t5 = a % b    // 取模
```

#### 一元运算指令
```
t1 = -a       // 取负
t2 = !a       // 逻辑非
```

#### 赋值指令
```
x = y         // 简单赋值
x = 5         // 常量赋值
```

#### 比较指令
```
t1 = a < b    // 小于比较
t2 = a == b   // 等于比较
t3 = a != b   // 不等于比较
```

#### 跳转指令
```
goto L1           // 无条件跳转
if x goto L1      // 条件跳转（真）
if !x goto L1     // 条件跳转（假）
```

#### 函数调用指令
```
param a           // 传递参数
param b
t1 = call f, 2    // 调用函数f，2个参数
return x          // 返回值
```

### 3.2 操作数类型

#### 变量
```
x, y, z          // 程序变量
```

#### 临时变量
```
t1, t2, t3       // 编译器生成的临时变量
```

#### 常量
```
5, 10, -3        // 整数常量
```

#### 标签
```
L1, L2, loop_start    // 跳转目标标签
```

## 4. 三地址码的重要作用

### 4.1 编译器中间表示

#### 前端到后端的桥梁
```
源代码 → AST → 三地址码 → 目标代码
```

三地址码作为编译器前端（语法分析、语义分析）和后端（优化、代码生成）之间的接口。

#### 语言无关性
不同的高级语言都可以转换为相同形式的三地址码，便于共享后端优化技术。

### 4.2 优化的基础

#### 局部优化
```
// 优化前
t1 = a + b
t2 = a + b    // 重复计算
x = t2

// 优化后
t1 = a + b
x = t1        // 消除重复计算
```

#### 死代码消除
```
// 优化前
t1 = a + b    // t1未被使用
x = c + d

// 优化后
x = c + d     // 删除死代码
```

#### 常量折叠
```
// 优化前
t1 = 2 + 3
x = t1 * y

// 优化后
x = 5 * y     // 编译时计算常量
```

### 4.3 代码生成的便利

#### 指令选择
三地址码的简单结构使得向目标机器指令的映射更加直接。

```
// 三地址码
t1 = a + b

// x86 汇编
mov eax, [a]
add eax, [b]
mov [t1], eax
```

#### 寄存器分配
临时变量为寄存器分配提供了清晰的目标。

```
// 寄存器分配前
t1 = a + b
t2 = t1 * c
x = t2

// 寄存器分配后（假设t1,t2分配到寄存器）
r1 = a + b    // t1 → r1
r2 = r1 * c   // t2 → r2
x = r2
```

## 5. 三地址码生成过程

### 5.1 表达式处理

#### 后序遍历AST
```c
// 原始表达式: (a + b) * c
```

**AST结构：**
```
    *
   / \
  +   c
 / \
a   b
```

**生成过程：**
1. 处理 `a + b` → `t1 = a + b`
2. 处理 `t1 * c` → `t2 = t1 * c`

### 5.2 控制流处理

#### 短路求值
```c
// 原始代码
if (a && b) { ... }
```

**三地址码：**
```
if !a goto false_label
if !b goto false_label
// then分支代码
goto end_label
false_label:
// else分支代码
end_label:
```

### 5.3 函数调用处理

```c
// 原始代码
int result = func(a, b + c);
```

**三地址码：**
```
t1 = b + c
param a
param t1
t2 = call func, 2
result = t2
```

## 6. 三地址码的优势

### 6.1 简单统一
- 指令格式统一，便于处理
- 操作简单，易于分析和优化

### 6.2 接近机器码
- 结构接近汇编语言
- 便于目标代码生成

### 6.3 优化友好
- 控制流和数据流清晰可见
- 便于各种优化技术的应用

### 6.4 可移植性
- 与具体机器架构无关
- 可以生成不同目标平台的代码

## 7. 实际应用场景

### 7.1 编译器设计
- GCC、LLVM等主流编译器都使用类似的中间表示
- 便于模块化的编译器设计

### 7.2 代码优化工具
- 静态分析工具
- 程序变换工具
- 性能分析工具

### 7.3 教学和研究
- 编译原理教学的重要内容
- 程序分析研究的基础表示
